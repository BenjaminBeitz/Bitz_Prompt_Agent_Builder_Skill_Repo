# Autonomous Agent Engineering Suite: OKF Index

Welcome to the **Autonomous Agent Engineering Suite**, containing tools to scan workflows for agent automation opportunities and systematically build production-ready agents.

---

## 🧭 Skills Catalog

| Skill | Author | Description |
| :--- | :--- | :--- |
| [`agent-opportunity-scan`](agent-opportunity-scan/SKILL.md) | Benjamin Beitz | Scans transcripts, command logs, and workflows to detect high-toil patterns suitable for autonomous agentification. Evaluates candidates across 3 archetypes (*solo-tool-user*, *multi-agent-squad*, *autonomous-sentinel*), computes AVS viability scores, and outputs specification dossiers. |
| [`build-agent`](build-agent/SKILL.md) | Benjamin Beitz | Spec-driven agent compiler that conducts a risk-weighted systems interview, generates complete Agent Specification Sheets, and scaffolds production-ready agents with Python micro-harnesses, tools, and rollback guards. |
