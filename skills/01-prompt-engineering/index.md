# Scientific Prompt Engineering Suite: OKF Index

Welcome to the **Scientific Prompt Engineering Suite**, a collection of 10 Google Antigravity skills strictly grounded in empirical NLP literature and the comprehensive taxonomy of **The Prompt Report** (Schulhoff et al., 2025).

---

## 🧭 Skills Catalog

| Skill | Description | Primary Methodologies |
| :--- | :--- | :--- |
| [`prompt-architect`](prompt-architect/SKILL.md) | Interactive Meta-Prompt Architect that interviews you to compose and stress-test the optimal prompt system. | Diagnostic grilling, trade-off tensor, component synthesis |
| [`prompt-audit`](prompt-audit/SKILL.md) | Audits existing prompts against empirical failure modes and invariants. | Length bias check, sycophancy detection, position bias |
| [`prompt-decomposition`](prompt-decomposition/SKILL.md) | Decomposes complex tasks into structured execution graphs. | Least-to-Most, Plan-and-Solve, DECOMP, Skeleton-of-Thought |
| [`prompt-ensembling`](prompt-ensembling/SKILL.md) | Multi-prompt ensembling pipelines and consensus generation. | Self-Consistency, MoRE, Universal SC Synthesizers |
| [`prompt-explainer`](prompt-explainer/SKILL.md) | Deconstructs prompt templates into interactive educational lessons. | Attention dynamics, Fig 2.2 mapping, failure mode analysis |
| [`prompt-few-shot`](prompt-few-shot/SKILL.md) | Few-shot prompt engineering optimizing exemplar selection and ordering. | KNN/Vote-K retrieval, AutoDiCoT, 6 exemplar decisions |
| [`prompt-generate`](prompt-generate/SKILL.md) | Direct, rapid prompt compiler across all 6 prompt families. | Zero-shot compilation, immediate artifact output |
| [`prompt-self-criticism`](prompt-self-criticism/SKILL.md) | In-context self-correction and critique loops to eliminate hallucinations. | Chain-of-Verification (COVE), ReverseCoT, multi-agent critique |
| [`prompt-thought-generation`](prompt-thought-generation/SKILL.md) | Advanced reasoning pathway engineering. | Step-Back abstraction, Thread-of-Thought, Tab-CoT |
| [`prompt-zero-shot`](prompt-zero-shot/SKILL.md) | Precision zero-shot transformation. | System 2 Attention (S2A), Re-reading (RE2), RaR, Role/Style |
